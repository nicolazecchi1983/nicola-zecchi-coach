# DS1.7 — Modals, Drawers & Overlays

STAFF Design System v1 centralizes overlay geometry and hierarchy in `src/design-system/overlays.css`.

Scope:
- modal/backdrop visual language;
- close controls;
- header/body/footer rhythm;
- Calendar event drawer;
- Match Report preview;
- Analysis Template Manager;
- adaptive mobile bottom/full-height behavior;
- safe-area-aware mobile footer actions.

Domain modules continue to own content, data and actions. The Design System owns presentation and overlay geometry.
