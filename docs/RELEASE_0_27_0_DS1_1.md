# STAFF 0.27.0 — DS1.1 Design System Foundation Contract

First release of the Design System v1 phase. No page redesign is included.

Changes:
- canonical foundation token roles expanded;
- touch minimum normalized to 44px and preferred target kept at 48px;
- primitive breakpoint converged from 720px to the canonical 760px mobile tier;
- primitive raw colors moved into tokens;
- product UI legacy text colors moved into canonical tokens;
- touch tokens moved to the foundation owner instead of responsive.css;
- automated DS1.1 foundation contract added to `npm run check`;
- legacy mobile-foundation check updated to follow the new token owner.

This release deliberately does not redesign Dashboard, Training, Match, Calendar or Roster.
